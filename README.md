# tools

Build tooling for the Lux Exchange workspace.

Extracted from [`luxfi/exchange`](https://github.com/luxfi/exchange) as a
standalone, Lux-original package (no third-party upstream).

## Contents

- `lux-nx/` — shared [Nx](https://nx.dev) TypeScript project configuration
  (`tsconfig.json`) used as a composite base for workspace projects.
